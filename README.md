# Code Quality Analyzer (Python + JavaScript) — No Database | Green-Black UI

A lightweight, offline, zero-database Code Quality Analyzer that analyzes Python and JavaScript files directly in the browser.  
It highlights:

- Cyclomatic-like complexity  
- Long functions  
- Unused imports  
- TODO comments  
- Long files  
- Basic JavaScript function detection  
- Maintainability indicators  

All analysis happens locally — no code is uploaded anywhere and no database is used.

---

## Features

### 1. Offline and Privacy-Friendly
All processing is done locally using Flask.  
Your code never leaves your machine.

### 2. No Database Required
Everything is temporary and in memory.  
Perfect for quick analysis and classroom use.

### 3. Green-Black User Interface
A clean, modern theme with:

- neon green accents  
- dark background  
- interactive cards  
- structured tables  

### 4. Python Static Analysis
Detects:
- Unused imports  
- Function lengths  
- Cyclomatic-like complexity  
- TODO comments  
- Long or large files  

### 5. JavaScript Analysis
Detects:
- Function definitions  
- Long files  
- TODO comments  

### 6. Multi-file Upload Support
Upload multiple `.py` and `.js` files at once.

### 7. Summary Dashboard
Shows:
- total files analyzed  
- total TODOs  
- total warnings
